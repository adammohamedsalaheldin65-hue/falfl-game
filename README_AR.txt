المحقق فلفل — نسخة Godot 4 خفيفة وقابلة للعب
================================================

دي مش صورة ولا مجرد فكرة. ده مشروع لعبة Godot 4 فيه:
- Log In / Sign In محليين.
- اختيار شخصية واسم.
- عالم 3D مصري Blockout خفيف.
- بيت مفتوح ومكتب.
- قسم شرطة.
- استلام ملف قضية في شنطة الشخصية.
- قراءة ملف القضية.
- مسرح جريمة ودليل.
- 5 مشتبه بهم.
- استجواب واختيار المجرم.
- مكافأة 15,000 جنيه.
- متجر لتطوير العربية واللبس والبيت.
- عربية قابلة للركوب والقيادة بعد شرائها.
- حركة Third Person وكاميرا بالماوس.

تشغيل المشروع:
1) نزّل Godot 4.x Standard من الموقع الرسمي.
2) فك ضغط ملف ElMohaqeq_Felfel_Godot.zip.
3) افتح Godot Project Manager.
4) اضغط Import واختار project.godot.
5) افتح المشروع واضغط F6/F5 أو زر التشغيل.

التحكم:
W A S D أو الأسهم = حركة
Shift = جري
الماوس = لف الكاميرا
E = تفاعل / ركوب العربية / النزول
Esc = تحرير أو إمساك الماوس

مهم:
الجرافيك الحالي Blockout معمول بالكامل من أشكال 3D بسيطة علشان حجم المشروع يفضل صغير جدًا.
ده أساس لعب حقيقي نقدر نبني فوقه موديلات وشخصيات وأصوات ومباني مصرية احترافية بعدين.


تحديث v3 — إحساس عالم مفتوح أقرب لألعاب الأكشن:
- كاميرا Third Person تتحرك أفقي ورأسي بالماوس.
- Zoom بعجلة الماوس.
- جري بـ Shift وقفز بـ Space.
- قيادة أسرع وأنعم، وفرامل بـ Space.
- عداد سرعة وحالة اللاعب ووقت داخل اللعبة.
- مؤشر مسافة للهدف.
- أرصفة وأعمدة إنارة وأكشاك وتفاصيل شوارع أكثر.
- شخصية أوضح برأس وجسم بدل كبسولة واحدة.
- العربية بقى لها عجلات وشكل أفضل.


تحديث v4 — City Life
====================
- NPCs ماشية في الشوارع.
- عربيات مرور متحركة.
- Mini-map خفيفة ومؤشر اتجاه الهدف.
- دورة نهار/ليل.
- إعدادات جودة Low / Medium / High.
- تفاصيل مدينة أكثر مع الحفاظ على حجم المشروع صغير.
- الهدف النهائي للنسخة الكاملة: 4–10 GB بعد إضافة موديلات وخامات وصوت حقيقي.

ملحوظة مهمة:
ملف المشروع الحالي صغير لأننا لم نضع Assets واقعية ثقيلة بعد.
الجرافيك الحقيقي 4–10 جيجا يحتاج موديلات 3D وخامات وصوت وأنيميشن مرخّصة/مُنشأة خصيصًا للمشروع.


تحديث v5 — Graphics Upgrade
============================
- سماء Procedural ودورة شروق/نهار/ليل.
- شمس وظلال حسب إعداد الجودة.
- خامات خفيفة للأسفلت والرمل والخرسانة والحوائط والطوب والخشب.
- نوافذ للمباني وبعضها مضاء.
- ممرات مشاة ومقاعد وصناديق شارع.
- واجهات محسنة للبيت والقسم والمطعم والمعرض.
- تفاصيل أكبر للعربية وفوانيس مضيئة.
- ما زلنا على Compatibility renderer عشان يفضل أخف على الأجهزة.

تحديث v5.2 — مدينة أكبر ومباني أكثر
====================================
- تكبير مساحة الأرض والطرق والأرصفة.
- زيادة كبيرة في عدد المباني غير القابلة للدخول.
- إضافة صفوف مباني ديكورية بعيدة لتدي إحساس مدينة أوسع.
- زيادة عدد أشجار النخيل وأعمدة الإنارة.
- زيادة عدد أماكن NPCs داخل المدينة.
- تمديد حدود حركة المرور لتناسب المدينة الأكبر.


تحديث v5.3 — تنويع المدينة
===========================
- أبراج أعلى وSkyline أوضح.
- مباني بارتفاعات مختلفة.
- شبابيك أمامية وجانبية.

تحديث v5.4 — Character Animation
=================================
- استبدال جسم الكبسولة بشكل آدمي خفيف: رأس، جسم، ذراعين، رجلين، إيدين وجزم.
- مشي متحرك Procedural.
- جري بحركة أسرع وميل بسيط للجسم.
- وضع قفز مختلف.
- Idle animation خفيفة أثناء الوقوف.
- شنطة الملفات ظاهرة على الشخصية.
- اللبس المختار يغير الجسم والأطراف معًا.
- اختلاف بسيط في شكل الشعر/غطاء الرأس حسب الشخصية.


تحديث v5.5 — Shop Interiors
============================
- المحلات الثلاثة بقى لها دخول فعلي من المدينة.
- أتيليه الملابس له رفوف، لبس معروض، مانيكانات وكاشير.
- معرض العربيات له صالة عرض فيها عربيات ديكورية وموظف مبيعات.
- مكتب تطوير البيت فيه نماذج صالون ومكتب قبل الشراء.
- الخروج من كل محل يرجعك لبابه في المدينة.
- الميني ماب تختفي داخل المحلات وتظهر بعد الخروج.
- الشراء لا يتم عند باب المحل؛ لازم تدخل وتروح للكاشير/المبيعات.


تحديث v5.6 — Story Interiors
=============================
- قسم الشرطة بقى مكان داخلي فعلي: استقبال، مكتب ملفات، انتظار، وجناح استجواب.
- البيت بقى له داخل منفصل فيه مكتب القضية، كنبة، سرير، دولاب ورفوف.
- مطعم عم رجب بقى له صالة ومطبخ ومخزن، والدليل الرئيسي موجود جوه.
- مراحل القضية بقت تعتمد على الدخول للأماكن:
  القسم -> البيت -> المطعم -> القسم.
- الخروج من كل مكان يرجعك لبابه في المدينة.
- الميني ماب تختفي داخل الأماكن وتظهر بعد الرجوع للشارع.


تحديث v5.7 — Case Bag + Save System
====================================
- زر B يفتح شنطة القضايا.
- الشنطة تعرض ملف القضية، الأدلة، المشتبه بهم وحالة القضية.
- Esc يفتح قائمة إيقاف فيها حفظ وتحميل.
- حفظ محلي في user://felfel_save.cfg.
- Auto-save بعد استلام الملف، قراءة الملف، اكتشاف الدليل، حل القضية والشراء.
- بعد تسجيل الدخول يظهر Continue لو فيه لعبة محفوظة.
- تحميل الحفظ يرجع الاسم والشخصية والفلوس والمرحلة والأدلة والمشتريات والمكان.


تحديث v5.8 — Account Storage
=============================
- بقى فيه Storage محلي حقيقي لعدة حسابات بدل حساب واحد فقط.
- الحسابات محفوظة في user://felfel_accounts.json.
- كل حساب له ID مستقل.
- الإيميلات لازم تكون Unique داخل الجهاز.
- كلمات السر لا تُحفظ كنص؛ يتم حفظ Salt + SHA-256 Hash.
- كل حساب له ملف Save مستقل:
  user://felfel_save_<account_id>.cfg
- تسجيل الدخول يحدث last_login.
- شاشة البداية تعرض عدد الحسابات المحفوظة.
- حفظ اللعبة مربوط بالحساب الحالي.


تحديث v5.9 — Online Accounts + Cloud Save
==========================================
- إضافة Online Backend مستقل باستخدام Supabase Auth.
- إنشاء حساب Online بالإيميل وكلمة السر.
- تسجيل الدخول من جهاز مختلف لنفس الحساب.
- Cloud Save مربوط بـ Supabase Postgres.
- RLS تمنع أي لاعب من قراءة أو تعديل Save لاعب تاني.
- Online Setup داخل اللعبة لإدخال Project URL وPublishable Key.
- ممنوع استخدام Secret/Service Role key داخل اللعبة.
- Local Save مازال موجود كـ fallback.
- Cloud Save يتم رفعه تلقائيًا مع Auto-save والحفظ اليدوي.
- عند تسجيل الدخول يتم فحص Cloud Save وعرض Continue لو موجود.
